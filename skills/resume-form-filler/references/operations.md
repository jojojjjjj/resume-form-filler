# 操作与故障分支

普通字段走 apply/verify，补结构与授权上传走同一 session 的 ui。helper 示例位置是 `.resume-form-filler/helpers/task.py`，不存个人事实进源代码；值从已核对的 profile 读取。上传后核对文件名/成功状态；上传简历会解析正文时前后各快照，不能静默覆盖人工草稿。

```sh
python3 tools/resume-fill.py ui --session 'DIR' --script '.resume-form-filler/helpers/task.py'
```

helpers 不得 switch_tab/new_tab、刷新用户页、读取 cookie 或直接调用招聘后台保存 API。所有补填最后仍通过 verify 核对；不得借 ui 绕过未知事实、覆盖确认和投递授权。

| 情况 | 处理 |
|---|---|
| 环境安装失败 | 保留 stderr，检查网络与 Python，重跑入口；不 sudo、不安装全局依赖、不使用另一个人的 runtime |
| 简历无文字/宏或文本框丢字 | 对照原文使用当前助手的文件/视觉能力，或请用户导出文本版；不以空提取建立 ready profile |
| 源指纹变化 | init 重新解析，合并旧补充事实，再 review-profile；不盲刷新哈希 |
| 没有目标 tab/多个相同 URL | 用户打开精确编辑页，或用 --target-id 指定；不关其他页 |
| 登录/MFA/验证码/隐私同意 | 使用者处理；保留草稿，继续独立资料核对 |
| 网页非空值冲突 | 先展示差异；真实确认后在计划记录覆盖授权 |
| 选择器不唯一/控件改版 | 重新快照和映射；同一字段失败两次停止并报告，不循环点击 |
| 自动补全/日期输入未保留 | 脚本有一次事件补发；仍失败则使用官方页面操作一次并读回，不能反复保存排查输入 |
| 下拉无精确选项 | 列实际选项，优先本站确认映射；不能跨站猜分类 |
| 后台暂停/滚动超时 | 保留页面和本地记录，说明阻塞；不切前台 |
| about:blank/目标 URL 变化 | 不改网站脚本或关闭浏览器；使用者返回编辑页后重新 start |
| 字段长度不足 | 不截断，基于原文整理候选短文；写 profile 或本站 overrides 后重建计划 |
| 附件未授权/无对应控件 | 询问本次新文件授权，或报告未上传；不能把照片/论文塞到简历解析位 |
| 保存被整份必填阻挡 | 列字段，checkpoint --local-only，继续独立模块；同一阻挡不重复点保存 |
| 保存超时/无提示 | 记录 save_unconfirmed 与恢复材料，检查页面；不直接重试导致双提交 |
| 保存后只出现提示/跳转 | 这是动作证据，读展示页或重新进入编辑页验证持久值和附件后再报告持久化核验 |

checkpoint 只接受已核实的保存控件，点击一次；拒绝“保存并投递/申请”。没有普通保存字样时按 site-template 的三项精确映射核验。具体 success-text 和 success-url-fragment 都从实际流程获取。投递始终单独授权。

复用的本站选择写 sites；操作记录写 runs；新事实按用户授权写 profile。不得把脚本输出、历史保存状态或网站解析结果升级为新的个人事实。
